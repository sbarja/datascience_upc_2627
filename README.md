# Data Science Applied to Energy Systems

Welcome to the official repository for the Master's course Data Science Applied to Energy Systems.
This repository contains all datasets, lab exercises, and practical materials used during class sessions.


## 📌 What's this repo for? 

* Content: Weekly exercises, hands-on tutorials, and course datasets.
* Tools: Worksheets are formatted as Python notebooks compatible with Jupyter Notebook and Google Colab.
* Updates: Content is updated on a weekly basis following the lecture schedule.
---
## 🚀 Getting Started
To get a local copy of this repository on your machine, follow these simple steps using your terminal or command prompt.

### **1. Clone the Repository**

Navigate into the project directory where you want to download the Github repo:
```bash
cd YOUR-FOLDER-NAME
```
Run the following command to download the repository into the FOLDER path:
```bash
git clone [https://github.com/sbarja/datascience_upc_2627.git](https://github.com/sbarja/datascience_upc_2627.git)
```

### **2. Update the Repository**
Since new exercises and datasets will be added weekly, make sure to pull the latest changes before each class:
```bash
git pull
```


---

## 💻 Running the Notebooks
Locally: Open terminal inside the directory and run `jupyter notebook` or `jupyter lab`.
Google Colab: Upload or import the `.ipynb` files directly into Google Colab. Datasets must be uploaded everytime you open the file in Google Colab.
